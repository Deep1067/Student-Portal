# 🎓 Student Portal Website

A fully responsive **Student Portal** built using **HTML5, CSS3 (Flexbox/Grid), and JavaScript**.  
This portal includes login, profile, courses, assignments, grades, attendance, events, feedback, contact, and FAQs pages — all with **dark/light theme switching** using CSS variables.

---

## 🚀 Features

- 🔑 **Login System** (Student ID & Password simulation with welcome popup)
- 👤 **Profile Page** (student details + photo)
- 📚 **Courses Page** (list of enrolled subjects)
- 📝 **Assignments Page** (course-wise assignments & deadlines)
- 📊 **Grades Page** (exam results & marksheet view)
- 📅 **Attendance Page** (detailed course attendance & percentages)
- 🎉 **Events Page** (events participated by students)
- 💬 **Feedback Form** (issues/suggestions submission)
- 📞 **Contact Page** (support details & quick contact form)
- ❓ **FAQs Page** (collapsible accordion-style answers)
- 🌗 **Theme Toggle** (light/dark mode with CSS variables, works on all pages)
- 📱 **Responsive Design** (Flexbox/Grid for mobile, tablet & desktop)
